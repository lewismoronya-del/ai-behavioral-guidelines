# Contributing

Thank you for helping improve AI Behavioral Guidelines.

## What is useful

Contributions may include:
- Clarifying wording while preserving the intended meaning.
- Identifying contradictions, gaps, ambiguous rules, or impractical requirements.
- Suggesting concrete improvements supported by examples or evaluation.
- Improving accessibility, organization, and usability.
- Providing evidence that a recommendation improves quality, reliability, or efficiency.

## Contribution principles

1. **Be specific.** Describe the issue, the consequence, and the proposed change.
2. **Preserve the purpose.** The framework prioritizes verified usefulness, honesty, safety, user objectives, and proportionate effort.
3. **Avoid complexity without benefit.** New rules should solve a real problem.
4. **Support consequential claims.** Include reliable references or reproducible examples where appropriate.
5. **Respect scope.** Prefer focused changes over unrelated rewrites.

## How to contribute

1. Open an issue describing the proposed change or problem.
2. For code or text changes, fork the repository and create a focused branch.
3. Submit a pull request explaining the rationale and any trade-offs.
4. Check that the change is consistent with the rest of the document and does not introduce contradictions.

There is no guarantee that every suggestion will be accepted. Maintainers should prioritize clarity, practical value, and consistency with the project's governing principles.
